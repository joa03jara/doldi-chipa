Configuración

🔴 No conectado a la nube

Sin conectar, los datos NO se comparten entre celulares y se pierden al cerrar.

1. Creá tu base de datos gratis

En firebase.google.com → creá un proyecto gratis → activá Firestore Database (modo prueba) → registrá una "app web" → copiá el bloque firebaseConfig que te muestra.

2. Pegá acá el firebaseConfig

Pegá solo la parte entre llaves { }, tal como te la da Firebase.

Hacé esto una sola vez por celular, en cada equipo que vaya a usar la app. Después queda guardado en ese celular para siempre.
